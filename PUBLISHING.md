# 📦 Publishing Guide\n\n## Step 1: Prepare for npm Publishing\n\nBefore publishing, ensure:\n\n✅ You have an npm account (create at https://www.npmjs.com)\n✅ You're logged in locally:\n```bash\nnpm login\n```\n\n✅ Package names are unique (check npm registry)\n✅ Version is correct in package.json\n✅ Code is built and tested\n\n## Step 2: First Time Publishing\n\n### For each repository, run:\n\n```bash\n# Build the project\nnpm run build\n\n# Run tests to ensure quality\nnpm test\n\n# Publish to npm\nnpm publish --access public\n```\n\n### Repository Order:\n1. **gitignore-gen** - Publish first (no dependencies on others)\n2. **commit-msg-lint** - Publish second\n3. **env-checker** - Publish third\n4. **readme-gen** - Publish last\n\n## Step 3: Create GitHub Releases\n\nFor each repository:\n\n```bash\n# Create a git tag\ngit tag v1.0.0\n\n# Push tag to GitHub\ngit push origin v1.0.0\n```\n\nThen go to GitHub → Releases → Draft a new release:\n- **Tag:** v1.0.0\n- **Title:** Release v1.0.0\n- **Description:**\n```markdown\n## 🎉 Initial Release\n\n### ✨ Features\n- Core functionality complete\n- Full test coverage\n- Production-ready\n\n### 📦 Installation\n```bash\nnpm install -g commit-msg-lint\n```\n```\n\n## Step 4: Set Up npm Token for CI/CD (Optional)\n\nFor automated publishing via GitHub Actions:\n\n1. Create npm token at https://www.npmjs.com/settings/~/tokens\n2. Go to repo Settings → Secrets → New secret\n3. Add secret: `NPM_TOKEN` = your token\n4. GitHub Actions will auto-publish on release\n\n## Step 5: Marketing Your Tools\n\n### 🚀 Share Across Platforms:\n\n**Twitter/X:**\n```\nJust published commit-msg-lint 🔍 - CLI that validates commit messages against conventional commit format. Perfect for dev teams!\n\n🔗 https://www.npmjs.com/package/commit-msg-lint\n🔗 https://github.com/SMIT-LAD-CODER/commit-msg-lint\n\n#DevTools #CLI #OpenSource\n```\n\n**Product Hunt:**\n- Launch each tool as separate product\n- Use 3-4 tools as suite in one post\n- Target dev tools category\n\n**Reddit:**\n- r/webdev - Share all 4 tools\n- r/programming - Post popular ones\n- r/node - Share JavaScript/Node tools\n\n**Dev.to:**\nWrite post: \"I Built 4 Dev Tools That Solve Common Problems\"\n- Explain each tool\n- Show usage examples\n- Link to npm and GitHub\n\n## Step 6: Add GitHub Topics\n\nFor each repo, go to Settings → About:\n\nAdd topics:\n- `dev-tools`\n- `cli`\n- `productivity`\n- `typescript`\n- `npm-package`\n- Tool-specific: `gitignore`, `conventional-commits`, `readme`, `env-vars`\n\n## Step 7: Create Badges for README\n\nAdd to each README:\n\n```markdown\n[![npm version](https://badge.fury.io/js/commit-msg-lint.svg)](https://badge.fury.io/js/commit-msg-lint)\n[![npm downloads](https://img.shields.io/npm/dm/commit-msg-lint.svg)](https://www.npmjs.com/package/commit-msg-lint)\n[![GitHub stars](https://img.shields.io/github/stars/SMIT-LAD-CODER/commit-msg-lint.svg)](https://github.com/SMIT-LAD-CODER/commit-msg-lint)\n```\n\n## Success Metrics 📊\n\nTrack these to measure success:\n\n- GitHub stars\n- npm downloads\n- GitHub forks\n- Social media mentions\n- Issues/PRs\n\n## Quick Checklist ✅\n\n- [ ] npm account created\n- [ ] Logged in locally (`npm login`)\n- [ ] All tests passing\n- [ ] Version bumped in package.json\n- [ ] Build successful (`npm run build`)\n- [ ] Published to npm (`npm publish`)\n- [ ] GitHub release created\n- [ ] Topics added\n- [ ] Badges added to README\n- [ ] Shared on social media\n- [ ] Submitted to Product Hunt\n- [ ] Posted on Dev.to\n- [ ] Shared on Reddit\n\n## Troubleshooting\n\n**\"Package name already taken\"**\n- Change package name in package.json\n- Re-run `npm publish`\n\n**\"ERR! 403 Forbidden\"**\n- Ensure npm token is valid\n- Check package name isn't reserved\n\n**\"WARN old version in node_modules\"**\n- Run `npm cache clean --force`\n- Retry publish\n\n---\n\n**Need help?**\nCheck npm docs: https://docs.npmjs.com/cli/v8/commands/npm-publish\n"
